## Article type for P1: "Data article" — templated, mandatory
- Submissions **without the official template are not accepted**. The
  template (Word) must be downloaded from the journal page — **TODO: save it
  into this folder before any DiB writing.**
- Data must be publicly available in a repository, linked from the article;
  repository DOI required (Zenodo fine; P0 blocks this venue too).
- Explicit rejection rule: datasets "with insufficient variables or samples"
  are not accepted — AerialFuseCV (125k instances, 15 classes) is safely
  clear of that bar.
- Purpose-built venue: peer-reviewed, curated, indexed, DOI'd data
  descriptions — the pure-descriptor framing that ISPRS OJPRS lacks.

## Template v19 (Dec 2024) — extracted from the official .docx in this folder
- **Title must include the word "data" or "dataset".**
- **Keywords 4–8**, semicolon-separated, **must not repeat title words**.
- **Abstract 100–500 words** (template overrides the generic guide's 250):
  collection process + dataset + reuse potential.
- **BACKGROUND section exists** in v19 (motivation/context for compiling the dataset).
- **References: MAX 20**, numbered `[n]` in-text; irrelevant self-citations
  penalized; the Zenodo dataset itself must be cited; related research
  article cited here if any.
- Data accessibility subfields: Repository name / DOI / Direct URL /
  Instructions for accessing.
- Methods section: explicitly no character limit.
- Ethics: standard compliance sentence when no human/animal/social-media data.
- No-funding boilerplate sentence provided by template.
- Template is partially locked for editing; instructional text must be deleted
  before submission.

## Confirmed template facts (from mirrors + guide)
- Specifications Table (Subject; Specific subject area ≤150 chars; Type of
  data; Data collection; Data source location; Data accessibility; Related
  research article), Value of the Data bullets (no background/interpretation/
  conclusions), Data Description, Experimental Design Materials and Methods,
  Limitations ≤200 words, Ethics + CRediT + Declaration of Competing
  Interests.
- **Abstract ≤250 words**; 1–7 keywords.
- **Review:** single anonymized, editor pre-screen, minimum two reviewers.
- Update articles exist as a type — relevant if AerialFuseCV ever gets a v2
  (e.g., refined masks, added modalities).
- Fast proofing cycle (2-day proof turnaround expected of authors).
