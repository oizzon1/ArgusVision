# Strategic Context Inbox

This directory is ATHENA's intake for papers, venue notes, competitor work,
supervisor material, and other context that may affect ArgusVision strategy.

## ATHENA Survey Rule

At startup and before any roadmap, venue, paper-scope, benchmark-design, or
research-positioning advice, ATHENA must:

- list this directory;
- read this README;
- read all `*_REVIEW.md` / `*_NOTES.md` files here;
- flag any unreviewed PDF or paper-like file before making strategic claims.

Raw PDFs are not automatically trusted. Each consequential paper should get a
short review note that records:

- what the work claims;
- whether it threatens, supports, or reframes ArgusVision;
- which roadmap items it affects;
- whether it needs citation, replication, or monitoring.

External-paper numbers are evidence about that paper only. They are not
ArgusVision results and must not be used as ArgusVision claims unless
recomputed into `results/`.
